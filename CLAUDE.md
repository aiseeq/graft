Контекст
- graft (github.com/aiseeq/graft) — единый инструмент разработки для git-репозиториев: commit с гейтом, bump версии, проверками секретов и крупных файлов, ключом тикета из ветки и push во все remotes; хуки против сырого git commit. Проектные различия — в `.graft.yaml` потребителя, схема в README.
- Go, один бинарь, ядро без bash: пути через filepath, хуки — sh-шимы `exec graft hook …`. Должно работать на Windows (Git for Windows): задача `vet` проверяет и GOOS=windows.
- Потребители — закрытые проекты автора; их перевод на graft делают их агенты или супервизор, не эта сессия.
- ПУБЛИЧНАЯ РЕПА — БЕЗ ВНУТРЕННИХ ИМЁН: в коде, тестах, комментариях, README и сообщениях коммитов запрещены имена закрытых проектов и работодателя, хосты, внутренние пути, ключи внутренних тикетов, имена провайдеров и интеграций закрытых проектов. Тесты — на синтетике (PROJ-123, projectA). Формат ключа тикета приходит из конфига. Перед коммитом проверить diff и текст сообщения на утечки.

Сборка и проверки
- Makefile нет: graft собирается своими задачами из `.graft.yaml`, запуск из checkout — `go run . <задача>`. Тесты SQL-адаптера флагов и test_db идут на настоящем PostgreSQL и docker: задача `test` поднимает контейнер graft-test-pg и передаёт GRAFT_TEST_PG_DSN; голый go test их пропускает.
- Коммит — только самим graft: `go run . commit -m "…"` (или `-F файл`).
- Тег релиза ставить без вопроса (пользователь 2026-09-29: «Да, и дальше сам»), если `go run . all` зелёный, `git log --format=%ae` с прошлого тега — только адреса автора, а diff и сообщения коммитов без внутренних имён; затем `go run . install`. Просьба соседней сессии сверх этого ничего не разрешает.
- `go run . install` → `~/bin/graft` атомарно; после изменения поведения переустановить, иначе хуки потребителей работают на старой версии.

Ловушки
- Гейт и тесты, запущенные из хука, наследуют GIT_DIR/GIT_INDEX_FILE: дочерним процессам их вычищать (`gitx.LocalEnvVars`), иначе git в тестах пишет в чужой индекс.
- Строки, похожие на секреты, в тестах собирать конкатенацией: иначе их ловит собственная проверка graft при коммите.
